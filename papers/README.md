# Papers

Draft for Eurographics 2027 (abstract 2026-09-25, full paper 2026-10-01).

    make          # regenerate numbers, build both PDFs
    make en       # English only
    make ko       # Korean only

`numbers.tex` is generated by `scripts/paper_numbers.py` directly from
`results/*/results.json`. No number in either PDF is typed by hand; if a run is
missing, its macro is absent and the build fails rather than printing a stale
value.

The layout here approximates CGF two-column so the draft compiles on this
machine. **Before submitting, move the body into the official
`egPublStyle-cgf` submission template (`EGauthorGuidelines-cgf-sub.tex`) from
SRMv2.** Submissions must be anonymised; technical papers are recommended to be
at most 10 pages including figures, excluding references.

Korean build uses `lualatex` with `fontspec` and NanumMyeongjo. `luatexja` is
not installed on this machine.

## References

`refs.bib` is generated by `scripts/make_bib.py` from metadata the arXiv API
returned, never retyped. Every entry was checked twice: the title we intended to
cite was matched against the title arXiv reports for that ID, and the abs page
was fetched and confirmed to return HTTP 200 with the paper on it. 38 candidates
were checked, 38 passed, none were discarded. Re-run the check with `make refs`.

Both papers cite all 38 entries; `bibtex` reports no warnings and no undefined
citations.
